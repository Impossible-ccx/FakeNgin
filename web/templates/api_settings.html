配置如何生效

01

仅使用你自己的 API

个人 API 配置仅对当前浏览器会话生效。每位使用者都需要填写自己的 API；未配置或已过期时，云端检测不可用。

已启动的批量任务仍使用提交时的配置，修改或清除只影响新检测。

02

临时保存在内存

个人配置有效期为 8 小时，只保存在服务端内存，服务重启后需重新填写。过期后重新保存你的 API，即可继续使用云端检测。

03

连接官方服务

只连接 DeepSeek 官方 API。保存配置不会验证密钥有效性或额度；如果调用失败，检测页面会显示对应错误。
